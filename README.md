# connect-portal

## カードのサムネイル

- 各カード上部の画像は `thumbs/` にあり、`python3 tools/make_thumbs.py` で全カード分を撮り直せる（新しいカードだけなら `--new`）。
- 教材を追加・修正したら、このスクリプトを実行してから push する。
- 元の絵文字表示に戻すときは、index.html の `<body class="thumbs">` を `<body>` にするだけ（絵文字は各カードに残してある）。

## カードのまとめ方（カードを増やしすぎないためのルール）

- 同じ種類の教材は1枚のカードにまとめ、カード内のボタンで選ぶ。
- 単元ごとに「やさしめ・標準」などがある確認テストは、学年（＋教科書）ごとに1枚のカードにし、単元は行（`<div class="prow"><span class="plab">単元名</span>ボタン…</div>`）で追加する。
  - 例：中3英語 文法確認テスト（ニューホライズン）に Unit 7 を足すときは、そのカードの `prows` に1行追加する（新しいカードは作らない）。
- 数学の確認テストは学年ごとに1枚。章が増えたらボタン（pill）を追加する。
