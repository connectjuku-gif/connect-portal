who・which・that（主格・目的格）・接触節（省略）をまとめて確認（標準）
3年　　組　　番　　名前：＿＿＿＿＿＿＿＿＿＿＿＿／100点
【ルール】制限時間は30分です。関係代名詞の全パターン（主格・目的格・省略）がごちゃまぜに出ます。
・「文の最初は大文字」「文の終わりは．（疑問文は？）」も採点の対象です。
・つづりのミスは減点します。見直しをしましょう。目標は80点以上です。
1次の文が正しければ○、まちがっていれば×を書きなさい。［4点×5］
  1. 先行詞に the only や all, every などの語がつくときは、which より that が好まれる。　
  2. 関係代名詞のあとの動詞は、関係代名詞そのものの人称・数ではなく、先行詞の人称・数に合わせる。　
  3. 目的格の関係代名詞を省略した文では、先行詞の直後に〈主語＋動詞〉が続く。　
  4. 主格の関係代名詞を使う文でも、目的格と同じように省略できる。　
  5. 先行詞が「人＋もの」のときは、関係代名詞に that を使うことが多い。　
2（　）内から最も適切なものを1つ選び、記号で答えなさい。［3点×6］
  1. She is the only teacher ( ア who　イ which　ウ that ) is respected by every student.
  2. This is the most beautiful picture ( ア who　イ which　ウ that ) I have ever seen.
  3. The language ( ア who　イ which　ウ that ) is spoken in Brazil is Portuguese.
  4. He bought a car ( ア who　イ which　ウ that ) was made in Germany.
  5. I have a friend ( ア who　イ which　ウ that ) speaks four languages.
  6. Do you know anyone ( ア who　イ which　ウ that ) can fix this computer?
3次の英文にはまちがいが1か所あります。その部分を正しい形に直して書きなさい。［4点×4］
  1. This is a pen which I use it every day.
  2. The students who studying English hard will pass the exam.
  3. She is a woman that know many languages.
  4. This is the bag which I bought it in Italy.
4次の英文を日本語に直しなさい。［3点×4］
  1. The book that was written by this author became a bestseller.
  2. The pictures which were taken by my brother are beautiful.
  3. Everything that she told me was true.
  4. The doctor people respect the most in this town is Dr. Sato.
5日本文に合う英文になるように、（　）内の語を並べかえて、全文を書きなさい。ただし、不要な語が1つずつ含まれています。（文の最初の文字は大文字に直し、最後の．（？）も書くこと）［6点×4］
  1. これは私が今までに読んだ中でいちばんおもしろい本です。　( the most interesting book / this / have / is / I / ever / which / read / that / . )
  2. 彼らが開発したシステムは多くの人々に使われています。　( the system / developed / they / is used / by many people / who / . )
  3. 私がいちばん尊敬している先生は田中先生です。　( the teacher / respect / I / the most / who / is Mr. Tanaka / . )
  4. 彼が私たちに見せてくれた写真は全て美しかったです。　( all the pictures / showed / he / us / that / were beautiful / . )

  2. 「これはあなたが探しているかばんですか」とたずねる文を書きなさい。　〔関係代名詞を省略した形（接触節）を使うこと〕

解答・解説

中学3年 英語 関係代名詞 総合問題（標準）　大問1［20点］・大問2［18点］・大問3［16点］・大問4［12点］・大問5［24点］・大問6［10点］＝100点
■ 出題範囲メモ
・対象：中3 関係代名詞 総合（who・which・that の主格、which・that の目的格、目的格の省略＝接触節）。特定の教科書の単元に限定せず、関係代名詞の全パターンを横断して出題。やさしめ版よりも、the only・最上級・受け身を含む文など、判断に迷うポイントを増やしています。
・大問ごとに出題形式が異なります（○×・3択・誤り訂正・和訳・並べかえ（不要語あり）・自由英作文）。
・各解答の右のタグは「間違えたときに確認するポイント」。

大問1　正誤判定（4点×5＝20点）

(1) ○that優先
the only・all・every などがつく先行詞には that が好まれる。
(2) ×主格
関係代名詞のあとの動詞は「先行詞」の人称・数に合わせる。
(3) ○接触節
省略された形（接触節）では、先行詞の直後に〈主語＋動詞〉が続く。
(4) ×省略
省略できるのは目的格のみ。主格は省略できない。
(5) ○that
先行詞が「人＋もの」のときは that を使う。

大問2　3択選択（3点×6＝18点）

(1) ウ thatthat優先
the only teacher という先行詞には that が好まれる。
(2) ウ thatthat優先
the most beautiful（最上級）がつく先行詞には that が好まれる。
(3) イ whichwhich/that
先行詞 The language はもの。which が基本（that も可）。
(4) イ whichwhich/that
先行詞 a car はもの。which が基本（that も可）。
(5) ア whowho
先行詞 a friend は人、主格。
(6) ア whowho
先行詞 anyone は人、主格。

大問3　誤り訂正（4点×4＝16点）

(1) it を削除目的格
目的格の関係代名詞 which があるのに it を重ねて使ってしまっている。which が it の代わりなので it は不要。
(2) studying → study主格
主格の関係代名詞 who のあとは動詞が必要（studying だけでは文が成立しない）。
(3) know → knows主格
先行詞 a woman（3人称単数）にあわせて knows にする。
(4) it を削除目的格
(1)と同じパターン。which があるので it は不要。

大問4　英文和訳（3点×4＝12点）

(1) この作者によって書かれた本はベストセラーになりました。受け身＋that
(2) 兄（弟）が撮った写真は美しいです。受け身＋which
(3) 彼女が私に話したことはすべて本当でした。that
(4) この町で人々がいちばん尊敬している医者はサトウ先生です。接触節

大問5　並べかえ（不要語あり）（6点×4＝24点）

(1) This is the most interesting book that I have ever read.不要語：which
(2) The system they developed is used by many people.不要語：who
(3) The teacher I respect the most is Mr. Tanaka.不要語：who
(4) All the pictures he showed us were beautiful.不要語：that

大問6　自由英作文（5点×2＝10点）

(1) I have a friend who can speak English and French.who
a friend のあとに〈who＋can speak〉を続ける。
(2) Is this the bag you are looking for?接触節
the bag のあとに you are looking for を続ける（関係代名詞なし）。
■ このテストのねらい（生徒への指示）
やさしめ版よりも「the only・最上級・受け身・不要語」など、判断に迷いやすいポイントを増やしています。間違えた問題の右のタグを見て、「先行詞が人かものか」「主格か目的格か」「thatが優先される場合はどんな時か」の3点を教科書で確認しよう。1回で満点を目指さず、どこで迷ったかを振り返ることが次につながります。
