    not as 〜 as …＝「…ほど〜ではない」。
  2. (2) あなたは放課後、何をするつもりですか。

    What are you going to do after school?未来
    疑問詞＋be動詞＋主語＋going to 〜?

    I didn't eat breakfast this morning.過去形

    ( paint / did / this picture / who / ? )

    不要な語：did。paint → painted。疑問詞が主語のときは Who＋動詞（過去形）〜?

    不要な語：is。no＋複数名詞＝「1つも〜ない」。
  3. (3) 早起きは健康によいです。
    ( good / get / getting up early / is / for your health / . )
    Getting up early is good for your health.動名詞
    不要な語：Get。〜ing のまとまりが主語。
  4. (4) 彼女は医者になりました。

4次の日本文に合う英文になるように（　）内の語句を並べかえなさい。ただし、不要な語が1つあります。また、下線部の語は必要があれば形を変えなさい。［1点×5］
  1. (1) どちらのかばんがあなたのものですか。
    ( which bag / what / yours / is / ? )
    Which bag is yours?疑問詞
    不要な語：What。「どちらの〜」は Which＋名詞。
  2. (2) 今、雪が降っています。
    ( it / snow / does / is / now / . )
    It is snowing now.進行形
    不要な語：does。snow → snowing。天気は It が主語。
  3. (3) わたしはたいてい10時に寝ます。
    ( at ten / am / usually / I / go to bed / . )
    I usually go to bed at ten.be動詞・一般動詞
    不要な語：am。usually は一般動詞の前。
  4. (4) いっしょに昼食を食べましょうか。
    ( do / lunch / shall / together / we / have / ? )
    Shall we have lunch together?助動詞
    不要な語：Do。「（いっしょに）〜しましょうか」は Shall we 〜?
  5. (5) あなたはそのとき、どこで走っていましたか。
    ( you / were / then / where / did / running / ? )
    Where were you running then?進行形
    不要な語：did。疑問詞＋were＋主語＋〜ing?
