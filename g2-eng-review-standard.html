［標準］No.1　／10点
1（　）に適する語を補い、全文を書きなさい。［1点×3］
  1. (1) 数学は英語ほど簡単ではありません。
    Math is   as easy   English.
    Math is not as easy as English.比較
    not as 〜 as …＝「…ほど〜ではない」。
  2. (2) あなたは放課後、何をするつもりですか。
    What   you   to do after school?
    What are you going to do after school?未来
    疑問詞＋be動詞＋主語＋going to 〜?
  3. (3) わたしは今朝、朝食を食べませんでした。
    I     breakfast this morning.
    I didn't eat breakfast this morning.過去形
    didn't のあとは原形。
2（　）内の語を適する形に直しなさい。ただし、1語とは限りません。［1点×1］
  1. (1) It ( rain ) tomorrow.
    will rain未来
    tomorrow なので未来（2語）。
3次の英文を（　）内の指示にしたがって書きかえなさい。［1点×1］
  1. (1) Our town has two parks. （There で始まる文に）
    There are two parks in our town.There is
    There are＋複数名詞＋場所。
4次の日本文に合う英文になるように（　）内の語句を並べかえなさい。ただし、不要な語が1つあります。また、下線部の語は必要があれば形を変えなさい。［1点×4］
  1. (1) この町には図書館が2つあります。
    ( in this town / is / two libraries / are / there / . )
    There are two libraries in this town.There is
    不要な語：is。複数なので There are。
  2. (2) あなたはなぜ早く起きたのですか。
    ( did / got / early / get up / why / you / ? )
    Why did you get up early?疑問詞
    不要な語：got。Why＋did＋主語＋動詞の原形 〜?
  3. (3) あなたは何時に家を出ますか。
    ( home / do / what time / are / you / leave / ? )
    What time do you leave home?疑問詞
    不要な語：are。What time をまとめて文頭に。
  4. (4) わたしには今日するべき宿題がたくさんあります。
    ( doing / to do / today / a lot of homework / have / I / . )

    She didn't write a letter.過去形
    didn't＋原形。wrote → write。
4次の日本文に合う英文になるように（　）内の語句を並べかえなさい。ただし、不要な語が1つあります。また、下線部の語は必要があれば形を変えなさい。［1点×5］
  1. (1) あなたはそのとき、どこで走っていましたか。
    ( then / did / were / running / you / where / ? )
    Where were you running then?進行形
    不要な語：did。疑問詞＋were＋主語＋〜ing?
  2. (2) いっしょに昼食を食べましょうか。
    ( do / we / shall / have / lunch / together / ? )
    Shall we have lunch together?助動詞
    不要な語：Do。「（いっしょに）〜しましょうか」は Shall we 〜?
  3. (3) わたしはたいてい10時に寝ます。
    ( at ten / am / usually / go to bed / I / . )
    I usually go to bed at ten.be動詞・一般動詞
    不要な語：am。usually は一般動詞の前。
  4. (4) 今、雪が降っています。
    ( it / is / does / snow / now / . )
    It is snowing now.進行形
    不要な語：does。snow → snowing。天気は It が主語。
  5. (5) どちらのかばんがあなたのものですか。
    ( what / is / yours / which bag / ? )
    Which bag is yours?疑問詞
    不要な語：What。「どちらの〜」は Which＋名詞。
