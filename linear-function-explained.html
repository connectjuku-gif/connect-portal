＜数学＞　中2　一次関数①　比例・反比例のおさらい中2　一次関数

一次関数の前に、比例・反比例と「代入」だけ軽く思い出そう。ここがわかれば、あとがラクになります。

■まずは「代入」（xに数を入れてyを求める）

例y＝2x＋1　で　x＝3のとき　→　y＝2×3＋1＝6＋1＝7
▶ xのところを数字に入れかえるだけ。かけ算（2×3）を先に計算してから、たし算。
例y＝−2x＋3　で　x＝−1のとき　→　y＝−2×（−1）＋3＝2＋3＝5
▶ xがマイナスの数のときは、かっこをつけて入れる。（−）×（−）＝（＋）になる。

■比例　y＝ax　（yがxのa倍）

x1234
y36912
  • xが2倍、3倍になると、yも2倍、3倍になる
  • y÷xがいつも同じ数 → それがa　（上の表はa＝3、y＝3x）
  • グラフは原点を通る直線

■反比例　y＝ax　（xとyをかけると、いつも同じ数）

x1236
y6321
  • xが2倍になると、yは12倍になる
  • x×yがいつも同じ数 → それがa　（上の表はxy＝6、y＝6x）
  • グラフは双曲線（曲がった2本の線）

■比例・反比例の式の求め方

例yはxに比例し、x＝2のときy＝10　→　a＝y÷x＝10÷2＝5　→　y＝5x
例yはxに反比例し、x＝3のときy＝4　→　a＝x×y＝3×4＝12　→　y＝12x

＜数学＞　中2　一次関数②　一次関数ってなに？中2　一次関数

一次関数は、「はじめにある量」＋「1ずつ増えるときの増え方」でできている式です。

■身近な例で考えよう

1本50円のえんぴつをx本買う。ほかに100円のノートを1冊買う。合計金額をy円とする。
えんぴつの本数 x（本）01234
合計金額 y（円）100150200250300
  • xが1増えるたびに、yは50ずつ増える　→　これがa（傾き）
  • x＝0のときのyは100　→　これがb（切片）
  • 式にすると　y＝50x＋100　　（y＝ax＋bの形）

■一次関数のきまり

y＝ax＋b
  • a＝傾き…xが1増えたとき、yがどれだけ増えるか
  • b＝切片…x＝0のときのyの値（グラフがy軸と交わるところ）
  • b＝0のときは、さっきの比例（y＝ax）になる

■式を見てaとbを読みとろう　（符号の−もいっしょに読む！）

式a（傾き）b（切片）
y＝3x＋232
y＝−2x＋5−25
y＝x−41−4
y＝−x−10
y＝4x−14−1
y＝12x＋3123
ここ注意！　y＝x−4のxは「1x」。a＝1。　y＝−xは「−1x＋0」。a＝−1、b＝0。　y＝x−4の「−4」はマイナスごとb。

■表にしてみよう　y＝2x＋3

x−2−10123
y−113579
1つのxに対して、yが1つ決まる。例：x＝−2 → 2×（−2）＋3＝−4＋3＝−1　／　xが1増えるたびにyは2増える（a＝2）

変化の割合とは、「xが増えたとき、yがどれくらい増えるか」の割合のこと。一次関数では、いつもa（傾き）と同じになります。

■変化の割合の求め方

変化の割合＝yの増加量xの増加量＝a
例y＝2x＋3　で、xが1から3まで増加するとき
xy
はじめ15
あと39
増加量＋2＋4
xの増加量は　3−1＝2　　yの増加量は　9−5＝4

■いちばん使う公式　yの増加量＝a×xの増加量

例y＝3x−2で、xが2増えると、yは　3×2＝6増える
例y＝3x−2で、xが2から6まで増加　→　増加量は6−2＝4　→　yは3×4＝12増える
▶ b（切片）は答えに関係ない！　aだけ見ればOK。

■aがマイナスのとき

y＝−2x＋5で、xが3増えると、yは　−2×3＝−6　→　6減る（マイナスは「減る」という意味）
▶ a＞0：xが増えるとyも増える（右上がり）　a＜0：xが増えるとyは減る（右下がり）

＜数学＞　中2　一次関数⑥　式を求める①（グラフから読む）中2　一次関数

■グラフから式を求める（y＝ax＋bのaとbを読む）

1グラフがy軸と交わる点を読む　→　切片b
2切片から右に1進んで、グラフ上の点まで上（下）にいくつ動くか数える　→　傾きa
3y＝ax＋bに、aとbを入れる
例　切片は−2
右1、上3 → 傾きは3
→　y＝3x−2

■例2　2本のグラフから式を求める

①　切片は−3　右に1進むと上に1　→　傾きは1　→　y＝x−3
②　切片は4　右に1進むと下に2　→　傾きは−2　→　y＝−2x＋4
▶ 右に1進んで下がるときは、傾きがマイナス！
▶ 格子点（方眼の交わる点）を通っているところを読む
▶ 傾きが1のときは、y＝1x−3と書かずy＝x−3

■「傾きと切片がわかっている」とき

そのままy＝ax＋bに入れるだけ。
例傾き−3、切片4の直線　→　y＝−3x＋4

＜数学＞　中2　一次関数⑦　式を求める②（1点・2点）中2　一次関数

■式の求め方A　傾きと、通る1点がわかっているとき

例傾き3で、点（2, 5）を通る直線の式
1傾きが3なので、y＝3x＋bとおく
2点（2, 5）のx＝2、y＝5を代入する　→　5＝3×2＋b
3bを求める　→　5＝6＋b　→　b＝−1
4答え　y＝3x−1

■式の求め方B　通る2点がわかっているとき

例2点（1, 3）、（3, 7）を通る直線の式
1傾きを求める　a＝yの増加量xの増加量＝7−33−1＝42＝2
　　（xもyも、同じ点の順番で引く。（3, 7）−（1, 3）なら、7−3と3−1）
2y＝2x＋bとおき、どちらか1点を代入　→　3＝2×1＋b　→　b＝1
3答え　y＝2x＋1　　（もう1点（3, 7）でも確かめよう：2×3＋1＝7 ✔）

■式の求め方C　平行な直線（傾きが同じ）

傾きが同じ2つの直線は平行　（bはちがってもよい）
例y＝2x＋1に平行で、点（1, 6）を通る直線　→　傾きは2　→　6＝2×1＋b　→　b＝4　→　y＝2x＋4

■よくあるミス

  • 代入のとき、xとyを逆に入れてしまう（点（2, 5）ならx＝2、y＝5）
  • 傾きを求めるとき、引く順番がそろっていない（符号が逆になる）
  • 求めたbを最後に式に入れ忘れる

＜数学＞　中2　一次関数⑧　文章題・交点中2　一次関数

■一次関数の文章題

文章を読んだら、「はじめの量」＝b、「1ふえる（へる）ごとの変化」＝a を探そう。
例1水そうに水が5L入っている。毎分2Lずつ水を入れる。x分後の水の量をyLとする。
はじめの量5L → b＝5　　1分ごとに2L増える → a＝2　→　y＝2x＋5
8分後は　y＝2×8＋5＝21L　　25Lになるのは　25＝2x＋5　→　2x＝20　→　x＝10分後
例2長さ30cmのろうそくに火をつけると、毎分2cmずつ短くなる。x分後の長さをycmとする。
はじめの長さ30 → b＝30　　1分ごとに2cm減る → a＝−2　→　y＝−2x＋30
5分後は　−2×5＋30＝20cm　　燃えつきる（y＝0）のは　0＝−2x＋30　→　x＝15分後
▶ 「へる」ときは、傾きaがマイナス。「○○のとき（y＝△）」と言われたら、yに数を入れて方程式を解く。

■グラフと座標軸の交点

y軸との交点 … x＝0を代入する（交点は（0, b）、つまり切片）
x軸との交点 … y＝0を代入して、xを求める
例　y＝3x−6
y軸：x＝0 → y＝−6　→　（0, −6）
x軸：y＝0 → 0＝3x−6 → 3x＝6 → x＝2　→　（2, 0）

■ちょっとレベルアップ　2直線の交点

2つのグラフが交わる点（交点）の座標は、2つの式を連立方程式として解いた答え。
y＝x＋1　と　y＝−2x＋7
x＋1＝−2x＋7　→　3x＝6　→　x＝2
y＝2＋1＝3　→　交点は（2, 3）
▶ 右辺どうしを「＝」で結ぶと、yが消える
