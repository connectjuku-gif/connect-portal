＜数学＞　関数の総復習①　比例・反比例関数の総復習

■比例　y＝ax

  • 式：y＝ax（a≠0）　aを比例定数という
  • xが2倍、3倍、…になると、yも2倍、3倍、…になる
  • y÷xの値はいつも一定で、aに等しい
  • グラフは原点を通る直線
    　a＞0：右上がり　a＜0：右下がり
  • 変化の割合は、いつもaで一定
例　x＝3のときy＝−12　→　a＝−12÷3＝−4　→　y＝−4x

■反比例　y＝ax

  • 式：y＝ax（a≠0）　xy＝a
  • xが2倍、3倍、…になると、yは12倍、13倍、…になる
  • xとyの積xyの値はいつも一定で、aに等しい
  • グラフは双曲線（なめらかな2つの曲線）
    　x軸、y軸とは交わらない／原点について対称
  • a＞0：第1・第3象限　a＜0：第2・第4象限
例　x＝2のときy＝6　→　a＝2×6＝12　→　y＝12x

■座標と象限／グラフ上の点

象限第1第2第3第4
（x, y）の符号（＋, ＋）（−, ＋）（−, −）（＋, −）
点がグラフ上にある　＝　その点の座標を式に代入すると等式が成り立つ
例：点（2, 8）がy＝2x²上にあるか → 2×2²＝8 ✔

＜数学＞　関数の総復習②　一次関数（式・変化の割合・グラフ）関数の総復習

■一次関数の式　y＝ax＋b

  • a＝傾き（＝変化の割合）　b＝切片（グラフとy軸との交点が（0, b））
  • 比例y＝axは、b＝0のときの一次関数（原点を通る）
  • グラフは直線　a＞0：右上がり　a＜0：右下がり　|a|が大きいほど急
  • 傾きが等しい2直線は平行　　　x軸との交点：y＝0を代入　y軸との交点：x＝0を代入

■変化の割合

変化の割合＝yの増加量xの増加量＝a（一次関数ではいつも一定）
  • yの増加量＝a×xの増加量
例　y＝3x−2で、xが1から4まで増加するとき
xの増加量は4−1＝3　→　yの増加量は3×3＝9

■グラフのかき方（3ステップ）

  • ①切片（0, b）に点を打つ
  • ②傾きaの分だけ進んだ点を打つ
    　右に1、上にa（a＜0なら下に|a|）
    　a＝nmのときは右にm、上にn
  • ③2点を通る直線をひく
左図：y＝2x＋1　切片1、傾き2
右図：y＝−12x＋2　切片2、傾き−12（右に2、下に1）

■よくあるミス（一次関数①）

  • 傾きの分母と分子を逆にする（右に進む数が分母、上に進む数が分子）
  • yの増加量＝a×xの増加量。かけ算を忘れてxの増加量をそのまま答える
  • 切片（y軸との交点）と、x軸との交点を混同する

＜数学＞　関数の総復習③　一次関数（式の求め方・交点・面積）関数の総復習

■直線の式の求め方

① 傾きと通る1点がわかる　傾き2、点（3, 5）を通る
　y＝2x＋bにx＝3, y＝5を代入 → 5＝6＋b → b＝−1　　y＝2x−1
② 通る2点がわかる　（1, 3）、（3, 7）を通る
　傾き＝7−33−1＝2 → y＝2x＋bに（1, 3）を代入 → 3＝2＋b → b＝1　　y＝2x＋1
③ 平行な直線　y＝3x−1に平行で、点（2, 4）を通る
　傾きは同じ3 → 4＝6＋b → b＝−2　　y＝3x−2
④ グラフから読み取る　切片が読めるならb、格子点（整数の点）を2つ見つけて傾きを求める

■2直線の交点（連立方程式）

交点の座標＝2つの式を連立方程式として解いた解
例　y＝x＋1　と　y＝−2x＋7
x＋1＝−2x＋7 → 3x＝6 → x＝2
y＝2＋1＝3　　交点は（2, 3）
※2つの式の右辺どうしを等しいと置くと、yを消せる

■直線と座標軸で囲まれた三角形の面積

  • x軸との交点（y＝0を代入）と、y軸との交点（x＝0を代入）を求める
  • 面積＝12×（x軸との交点のx座標）×（切片）
例　y＝−12x＋3
y＝0のときx＝6、x＝0のときy＝3
面積＝12×6×3＝9

■よくあるミス（一次関数②）

  • 傾きを求めるとき、xとyの引く順番がそろっていない（符号ミス）
  • 座標（x, y）の代入の順番を逆にする
  • 面積の計算で12をかけ忘れる／座標のマイナスを長さにそのまま使う（長さは正の数）

＜数学＞　関数の総復習④　関数 y＝ax²（特徴・変域・変化の割合）関数の総復習

■y＝ax²の特徴

  • yはxの2乗に比例する（a≠0）　aは比例定数
  • グラフは放物線　原点が頂点で、y軸について対称
  • a＞0：上に開く　y≧0、最小値0（x＝0のとき）
  • a＜0：下に開く　y≦0、最大値0（x＝0のとき）
  • |a|が大きいほどグラフの開き方は小さい（y軸に近づく）
  • aと−aのグラフはx軸について対称
x−3−2−10123
x²9410149
2x²188202818
※xの値と−xの値で、yの値は同じになる

■yの変域（xの変域が決まっているとき）

グラフをかいて、xの変域の両端と、頂点（x＝0）を調べる　（a＞0の場合。a＜0は上下が逆）
変域に0を含む場合　y＝2x²（−1≦x≦3）
最小値はx＝0で0　最大値は、0から遠いx＝3で18
→　0≦y≦18
変域に0を含まない場合　y＝x²（1≦x≦3）
x＝1で1、x＝3で9（増えていくだけ）
→　1≦y≦9

■変化の割合（一次関数との大きな違い）

  • y＝ax²の変化の割合は一定ではない（一次関数はいつもaで一定）
  • xがpからqまで増加するときの変化の割合＝a（p＋q）
例　y＝x²で、xが1から3まで増加するとき
変化の割合＝1×（1＋3）＝4　（確かめ：9−13−1＝4）

■式の求め方

通る1点の座標をy＝ax²に代入して、aを求める
例　点（2, −12）を通る　→　−12＝a×2²　→　a＝−3　　y＝−3x²

＜数学＞　関数の総復習⑤　関数 y＝ax²（放物線と直線）・まとめ関数の総復習

■放物線と直線の交点・三角形の面積

交点の座標＝2つの式を連立して解く（yを消してxの2次方程式をつくる）
例　y＝x²　と　y＝x＋2　の交点A、B（Aのx座標は負）
x²＝x＋2 → x²−x−2＝0 → （x＋1）（x−2）＝0 → x＝−1, 2
y座標はy＝x²から　A（−1, 1）　B（2, 4）
△OABの面積の求め方
直線y＝x＋2とy軸の交点をC（0, 2）とし、y軸で2つの三角形に分ける
△OAC＝12×OC×（Aのx座標の絶対値）＝12×2×1＝1
△OBC＝12×2×2＝2　　→　△OAB＝1＋2＝3

■関数の利用（y＝ax²の形になるもの）

  • ボールが落ちる距離（x秒間にym）、車のブレーキをかけてから止まるまでの距離（速さの2乗に比例）など
  • 文章題では、表の値から比例定数aを求める → 式を立てる → 求めたい値を代入、の順に進める
例　ボールを転がして、x秒間にym進むとき、y＝2x²。5秒後は 2×5²＝50m。32mに達するのは 2x²＝32 → x²＝16 → x＝4秒後（x＞0）
