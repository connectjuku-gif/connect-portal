    Ken   eat breakfast.
    Ken doesn't eat breakfast.be動詞・一般動詞
    3人称単数の否定は doesn't。
  2. (2) あなたは今週末、何をするつもりですか。
    What are you going to   this weekend?
    What are you going to do this weekend?疑問詞
    going to のあとは原形。
  3. (3) 冷蔵庫にりんごはありますか。
      there any apples in the fridge?

    apples は複数なので Are there。

    most beautiful比較
    長い語の最上級は most＋原級（2語）。

  1. (1) Mt. Fuji is higher than any other mountain in Japan. （the を使ってほぼ同じ意味の文に）
    Mt. Fuji is the highest mountain in Japan.比較

4次の日本文に合う英文になるように（　）内の語句を並べかえなさい。ただし、不要な語が1つあります。また、下線部の語は必要があれば形を変えなさい。［1点×4］
  1. (1) あなたたちは同じ学校の生徒ですか。
    ( do / are / you / at the same school / students / ? )
    Are you students at the same school?be動詞・一般動詞
    不要な語：Do。be動詞の疑問文は be動詞を文頭に。
  2. (2) もし明日晴れたら、テニスをしましょう。
    ( it / let's / if / tomorrow / will / is sunny / play tennis / . )
    Let's play tennis if it is sunny tomorrow.接続詞
    不要な語：will。if のあとは未来のことでも現在形（is）。
  3. (3) わたしは彼が正しいと思います。
    ( he / is right / I / that / think / it / . )
    I think that he is right.接続詞
    不要な語：it。think that＋主語＋動詞。that は省略できる。
  4. (4) 窓を開けましょうか。
    ( shall / open / the window / do / I / ? )
    Shall I open the window?助動詞

4次の日本文に合う英文になるように（　）内の語句を並べかえなさい。ただし、不要な語が1つあります。また、下線部の語は必要があれば形を変えなさい。［1点×4］
  1. (1) 明日は雨が降るでしょう。
    ( is / will / rain / tomorrow / it / . )
    It will rain tomorrow.未来
    不要な語：is。will＋動詞の原形。
  2. (2) ケンはトムより背が高いです。
    ( is / Ken / tall / more / than Tom / . )
    Ken is taller than Tom.比較
    不要な語：more。tall → taller。比較級＋than＝「〜より…」。
  3. (3) この町にはいくつの公園がありますか。
    ( there / much / are / in this town / how many parks / ? )
    How many parks are there in this town?疑問詞
    不要な語：much。How many＋複数名詞＋are there 〜?
  4. (4) わたしはピアノをひくことが好きです。
    ( like / the piano / play / I / playing / . )
    I like playing the piano.動名詞
    不要な語：play。like＋〜ing＝「〜することが好き」。
